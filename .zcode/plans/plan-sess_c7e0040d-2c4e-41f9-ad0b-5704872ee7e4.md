# v0.23 实施计划（修订版）：数值表驱动 + 3 新职业与终极合成 + 战斗加速/暂停 + 战斗回放

## 第一步：数值表驱动（基建）

- 新增 `unitstats.h/.cpp`：`UnitStats{hp,atk,heal,range,moveSpeed,attackSpeed,skillDmg,cost,sellPrice,goldValue,name}` 单例 DB；启动读 `config/unitstats.json`，每字段带编译期内置默认值（配置缺失/损坏不崩）
- 键：warrior/mage/support/assassin/hunter/knight/shaman/boss/ultimate；ultimate 键额外存 `hpRatio=0.8 / atkRatio=0.8 / defaultHp / defaultAtk / skillDmg=120`（合成公式与默认档）
- hero/enemy 构造数值、getAttackDamage/getAttackRange/getHealAmount、heroCost/enemyGoldValue、renderHeroInfo 属性显示全部改读 DB——玩家/敌方共用一份表根除漂移；名字（A-/E- 前缀）来自 DB

## 第二步：新职业 ×3 + 终极角色

- 枚举追加在 Boss 后（存档/联机整数兼容）：`{…Boss=4, Hunter=5, Knight=6, Shaman=7, Ultimate=8, COUNT=9}`
- **射手 Hunter**：HP70/ATK30/射程3/攻速100；普攻=箭矢弹道（ProjectileEffect 颜色参数化复用火球渲染）；技能"三连箭"3×70%ATK
- **骑士 Knight**：HP220/ATK12/射程1/移速90；普攻=蓝白斩击；技能"盾击"2×ATK+自回 20% 最大 HP
- **萨满 Shaman**：HP60/ATK12/射程3；普攻=绿色弹道；技能"腐蚀之种"目标及相邻敌人中毒（复用燃烧 DOT 管线，Unit 加 `m_dotGreen` 标记、火苗渲染变绿）
- **终极 Ultimate（按你的要求修订）**：
  - **动态数值**：合成时 HP = 80% × Σ(三个素材的 3 星基础 HP)，攻击 = 80% × Σ(3 星基础攻击)；基础值 = DB 数值×星级系数，**不含装备加成**（装备另行合集继承，避免双算）。示例：战士+刺客+骑士 → HP≈1072/ATK≈262；法师+辅助+萨满 → HP≈608/ATK≈70
  - **技能"天罚"提升**：对全场敌方 120 伤害（原案 60 翻倍，JSON 可调）
  - 射程 2/攻速 110/移速 60 固定；立绘 World04_003 Outlaw
  - **永不可再次升级**：不参与任何升星/合成（tryStarUp 显式拒绝）、无星级星标显示、不可作为终极合成素材；不可招募，售价 500
  - 自定义难度选 Ultimate 作对手时用 DB 默认数值档
- 代码落点：unit.h/cpp 四个新技能、hero/enemy 各 4 新类（Ultimate 双阵营，动态攻击存于单位成员 `m_dynamicAtk`）、createUnitFromPool ×9、unitvisuals 颜色/标签/英文名/立绘表、UNIT_TYPE_NAMES 扩容、findHealTarget tie-break、普攻特效分支、图例两列布局

## 第三步：终极合成（3 个不同职业 3 星 → 终极）

- `tryStarUp()` 新分支：拖拽 3 星到不同职业 3 星上 → 棋盘+回收槽搜第三个不同职业 3 星 → 三者消耗（按上述公式计算动态数值）→ 装备按 EquipType 合集继承、多余进掉落区 → 生成 UltimateHero
- `checkAutoStarUp()` 同规则自动检测；合成入口提示文字

## 第四步：全部出现池接入

- 招募池 7 职业（Ultimate 除外）替换 `types[rand()%4]`；关卡 3 处生成遍历 7 职业（L1 敌 4→7 个，难度靠 JSON 调低新职业数值平衡）；无尽演化 `rand()%7`（初始编成保持原 4 职业）；自定义难度循环含 Ultimate（与 Boss 同样锁星级）；`tests/test_custombattle.cpp` 循环断言同步更新；羁绊保持原 4 职定义

## 第五步：战斗加速/暂停

- `m_battleSpeed(1/2/3)`/`m_battlePaused`；暂停跳过帧推进与 processCombatFrame（渲染照常、特效冻结）；切速 `setInterval(20/speed)`；右侧开始按钮下方 `[⏸][1x][2x][3x]` 仅战斗阶段显示，战斗结束复位；联机同样可用（纯帧驱动不影响确定性）

## 第六步：战斗回放（只存上一局）

- 战役/无尽/自定义开战入口补显式播种（联机已有）；录 `m_lastReplay={模式标签, seed, heroes[], enemies[], recycle[]}`（pvpReady 序列化抽成通用 serializeSide）；左栏固定区「回放上局」按钮；startReplay 快照当前棋盘+回收槽 → 清场重建 → srand(seed) → 回放模式开战
- 回放隔离：tryEquipDrop/击杀金币跳过；endLevel 回放分支只弹统计并恢复战前快照；**顺带修复 m_units.clear() 前回收槽指针悬挂的既有隐患**（PvP 共用路径）
